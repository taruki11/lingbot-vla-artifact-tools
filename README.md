# LingBot-VLA Artifact Utilities

This code-only snapshot contains small archive, restore-verification, and DCP state-inspection utilities developed around a LingBot-VLA workflow. It does not include the upstream model implementation.

## Scope

No model weights, checkpoints, datasets, evaluation logs, credentials, or upstream source files are included. Runtime directories are configured through environment variables such as `LINGBOT_PROJECT_ROOT`, `LINGBOT_RUNS_DIR`, `LINGBOT_RUNTIME_RUNS`, and `ROBOTWIN_ROOT`.

## Status and license

These utilities are workflow-specific and are not an official LingBot-VLA release. No open-source license has been selected; public visibility does not grant reuse rights. Verify upstream and dependency licenses before reuse.
