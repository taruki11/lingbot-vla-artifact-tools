# LingBot-VLA 归档工具

这是围绕 LingBot-VLA 工作流整理的源码快照，包含归档、恢复核验和 DCP 状态检查小工具。不包含上游模型实现。

## 范围

不含模型权重、检查点、数据集、评测日志、凭据或上游源码文件。运行目录通过 `LINGBOT_PROJECT_ROOT`、`LINGBOT_RUNS_DIR`、`LINGBOT_RUNTIME_RUNS` 和 `ROBOTWIN_ROOT` 等环境变量配置。

## 状态与许可

这些工具面向特定工作流，不是 LingBot-VLA 官方发布。尚未选择开源许可证；公开可见不代表授予使用许可。复用前请核验上游代码与依赖许可。
